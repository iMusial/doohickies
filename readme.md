# doohickies
Random side projects that are too small for their own repo

## [ipecho.py](ipecho.py)
Python script that prints your public IP along with some geolocation data by sending a get request to ipecho.io, then parsing the JSON in the response. 

## [lynx.py](lynx.py)
Python script that uses the Brave search API and returns search results and their descriptions, given a key word. Inspired by the tool "lynx" from the game HackHub.
